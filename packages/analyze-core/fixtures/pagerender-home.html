What exactly does Pagerender do?

Crawlers that do not run JavaScript see an empty page on a JavaScript site. Pagerender loads each of your pages in a real Chrome browser and waits for the content to appear. Search engine and AI crawlers get the finished HTML instead. Pagerender also fills in missing titles, descriptions, canonical tags and alt text, and adds structured data. Connect Google Search Console and the dashboard shows you, page by page, what Google has indexed. It can submit your sitemaps as well. We use that data only to show you your own results.

Do AI crawlers run JavaScript?

No. Googlebot is the one major crawler that executes JavaScript, and it does so in a queued second pass. The AI crawlers that read pages in order to answer questions, including OAI-SearchBot, PerplexityBot and Claude-SearchBot, read the HTML they are served and stop there. A site that assembles its content in the browser is blank to all of them.

When should I use prerendering instead of server-side rendering?

Server-side rendering is the better answer whenever you can do it, because it serves visitors and crawlers the same finished HTML with no second copy of the page to keep in step. Prerendering is for the cases where that rewrite is not happening: a framework that cannot render on the server, a build nobody owns any more, a third-party iframe you do not control, or a deadline that will not move.

Is serving crawlers rendered HTML the same as cloaking?

No, as long as the crawler gets the same content a visitor gets. Pagerender serves the page after JavaScript has run, which is what the visitor sees once the app finishes loading. Cloaking means showing a crawler content a visitor never sees, and the terms of service forbid using Pagerender that way.

How do I check what a crawler sees on my site?

Request the page with curl and no JavaScript engine, then read the body: curl -A "OAI-SearchBot" https://example.com/. If the response is a nearly empty div with a script tag, that is what the crawler indexes. The crawler check on the Pagerender home page does the same fetch and shows the text, headings and links a crawler would extract.

How long does setup take?

Between 1 and 15 minutes, depending on where you put it. There are 7 integrations: a Cloudflare Worker that installs in one click, Nginx, Apache, Express middleware, Next.js middleware, Nuxt server middleware, and a WordPress plugin. Each one matches the incoming user agent, forwards crawler requests to Pagerender, and passes everything else through untouched.

Does this slow down real visitors?

No. Every integration checks the user agent first and forwards anything that is not a crawler straight to your origin, without waiting on Pagerender. A visitor request never enters the render path, so the page they get and the time they wait for it are the ones your site already produces.

What happens if Pagerender is unreachable?

The integration falls back to your origin. The Cloudflare Worker, the Express middleware, the Next.js middleware and the Nuxt handler all catch the failure and pass the request through, so a crawler sees the page your site would have served anyway rather than an error. The failure mode is the site you had before, not a broken one.

What happens after the page is rendered?

Rendering is the first of three parts. Pagerender reads each URL coverage state from Google Search Console, so you see which pages Google kept and which it filed as crawled but not indexed. An agent then spends the daily indexing quota on the pages with the most to gain and records why it picked each one. Google accepts 200 URL submissions a day per property and caps URL inspection at 2,000 a day, so ranking the queue is the part that matters.

Does rendering for AI crawlers bring traffic?

Only for the ones that cite. Pagerender separates crawlers that read a page in order to answer a question and link back from crawlers that collect text for model training and never do. Serving a training crawler finished HTML costs a render and buys no visits, so you choose which group you pay to render for.
